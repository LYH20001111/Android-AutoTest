(Internal Release)version: 2.0.0 time20210528
1. Changed:
(1) Applied "Core Package + Plugin Packages" pattern to NSDK. Core package only supports the cards for EMV/Financial transaction (Magnetic stripe card/EMV Contact card/EMV Contactless card) while other cards(e.g., M1, Felica card) supported by plugin card package.
(2) Refactored NSDK package namespace as below:
    * For Core Package:
      * com.newland.nsdk.core.api.common.*
      * com.newland.nsdk.core.api.internal.*
      * com.newland.nsdk.core.api.external.*
    * For Plugin XXX Package:
      * com.newland.nsdk.plugin.xxx.api.common.*
      * com.newland.nsdk.plugin.xxx.api.internal.*
      * com.newland.nsdk.plugin.xxx.api.external.*
(3) Refactored card module as below:
    * "CardReader" is responsible for card searching.
    * Instances of concrete card types shall be created directly or after card searching to communicate with cards.
(4) Followed some naming conventions, e.g.:
    * Rename "DeviceBasic" to "DeviceManager", "PinInput" to "PINEntry", "SmartCard" to "ContactCard".
    * All uppercase or lowercase letters for abbreviations, e.g., rename "EmvL2Service" to "EMVL2Service", "PinBlock" to "PINBlock", "generateMac" to "generateMAC".
    * Plural form for parameter class, e.g., "PINEntryParameters", "CardReaderParameters".
(5) Supported firmware version check when initializing NSDK modules. "ErrorCode.NEED_UPDATE" will be thrown if the version is too low to use NSDK.
(6) "NSDKModuleManager" to manage internal modules, "ExtNSDKModuleManager" to manage external modules.
(7) [Internal] Allowed PIN length of 0 to support ByPass.
(8) [Internal] Updated EMV L2 JNI library.
(9) [Internal] Used "RSAKey" instead of "modulus" and "exponent" for "startOfflinePINEntry" method.
2. Fixed:
(1) [Internal] Fixed some settings bugs.
3. Added:
(1) [Internal] Added UART3Port for RS232 and PINPAD port communication.
4. Removed:
(1) Removed SM algorithm.
