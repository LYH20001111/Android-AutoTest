# Capability: 运行部分连续案例

## Purpose

定义"运行部分连续案例"（选项 3）的输入状态生命周期：允许用户输入起始与结束案例号后一次执行区间内全部案例，并保证执行开始后返回输入界面时输入状态已清空。

## ADDED Requirements

### Requirement: 执行开始后输入状态清空

运行部分连续案例确认执行并跳转执行详情页后，返回 ExecutionFragment 时 SHALL 不保留本次输入的起始/结束案例号：起始与结束案例号 SHALL 重置为未输入状态，界面按钮 SHALL 恢复默认文案。

#### Scenario: 返回时输入状态已清空

- **WHEN** 用户输入起始与结束案例号并确认开始执行，随后从执行详情页返回 ExecutionFragment
- **THEN** 起始/结束案例号按钮显示默认文案，界面无之前输入的案例号残留
